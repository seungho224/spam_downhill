# Spam Downhill

## 실행

Three.js를 CDN에서 불러오므로 인터넷 연결이 필요합니다. ES 모듈은 브라우저의 `file://` 직접 열기에서 제한될 수 있으니, VS Code의 Live Server로 `index.html`을 열거나 프로젝트 폴더에서 아래 명령으로 로컬 서버를 실행하세요.

```powershell
py -m http.server 8000
```

그다음 `http://localhost:8000`에 접속합니다.

## 파일 구성

- `index.html` — 화면 구조와 게임 화면 요소
- `css/style.css` — HUD, 시작/결과 화면, 반응형 스타일
- `js/main.js` — 입력, 게임 상태, 프레임 루프
- `js/scene.js` — 1인칭 카메라, 도로/도시/인도, 차량/장애물, 웍과 스팸 렌더링
- `js/physics.js` — 속도, 조향, 점프, 충돌과 주행 점수
- `js/cooking.js` — 스팸 7개의 무작위 비중첩 배치, 조리 접촉/탄 정도, 무작위 뒤집기 높이와 맛 점수
- `js/ui.js` — HUD, 조리 타이밍 안내, 점수 결과 화면
- `js/utils.js` — 공통 수학/재질 도우미

## 조작

- `A` / `D`: 좌우 조향
- `W`: 장애물을 점프로 뛰어넘기
- 화면 클릭 (`F`): 스팸 뒤집기
- 약 3회 뒤집으면 스팸이 완성됩니다. 매 게임마다 3초 폭의 적정 뒤집기 구간이 6~9초, 7~10초, 8~11초 중 무작위로 정해집니다. 조리 전에는 흰색 마블링이 보이고 완성 시 검은 탄 자국이 더해집니다. 차와 정면 충돌 시 20점, 스치면 10점이 감점되며 주행 점수가 0점이 되면 게임 오버입니다. 다른 장애물 충돌은 10점 감점되며, 충돌 시 화면이 옅은 주황색으로 짧게 점멸합니다. 점프는 더 높고 짧게 조정했고 차도 점프로 피할 수 있습니다.
